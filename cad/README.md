# cad

PCB rails for mounting boards on an IKEA SKÅDIS pegboard.

| File | What |
|---|---|
| `skadis-pcb-rail.fcstd` | FreeCAD source |
| `skadis-pcb-rail-metro-inserts-rear-mount.3mf` | Metro rail, with inserts, rear mount |
| `skadis-pcb-rail-feather-left-inserts.3mf` | Feather rail, left |
| `skadis-pcb-rail-feather-right-inserts.3mf` | Feather rail, right |
| `skadis-pcb-rail-no-inserts.3mf` | Rail with no inserts |

The hooks and T-nuts used on the farm are other people's designs and are not
in this repo. Links and the sizes used are in
[docs/mounting.md](../docs/mounting.md).
